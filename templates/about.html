About This Project

AI-powered dental radiography analysis using deep learning

Project Objective

This system uses convolutional neural networks to automatically classify dental radiograph images into one of five categories:

  • Cavity — bacterial decay in tooth enamel
  • Fillings — existing dental restorations
  • Impacted Tooth — unerupted or partially erupted teeth
  • Implant — artificial tooth root replacements
  • Normal — healthy teeth with no pathology

The goal is to assist dental professionals by providing a fast, consistent second opinion from radiograph images.

Dataset

The model was trained on the Dental Radiography Dataset sourced from Kaggle.

SplitImages
Training25,136
Validation2,812
Test1,649
Total29,597

Significant class imbalance handled using softened class weights during training.

Technology Stack
  • TensorFlow / Keras — model training
  • VGG16 — best performing architecture (90.33%)
  • Flask — web application framework
  • SQLite — user authentication database
  • Bootstrap 5 — responsive UI
  • scikit-learn — evaluation metrics
  • Google Colab T4 GPU — training environment
Disclaimer

This tool is a research prototype and should not be used as a substitute for professional dental diagnosis.

Always consult a qualified dentist or oral health professional for:

  • Diagnosis of dental conditions
  • Treatment planning
  • Interpretation of radiographs
  • Medical advice of any kind

The model has known limitations — particularly with Cavity detection (F1: 0.22) due to limited training samples.
